# OpenSCAD Generator Frontend

Modern React + Vite.js frontend for OpenSCAD Code Generator.

## Kurulum

```bash
cd frontend
npm install
```

## Çalıştırma

```bash
npm run dev
```

Frontend http://localhost:3000 adresinde çalışacak.

## Backend Bağlantısı

Backend API'nin http://localhost:5000 adresinde çalışması gerekiyor.

Vite proxy ayarları `vite.config.js` dosyasında yapılandırılmıştır.

## Build

Production build için:

```bash
npm run build
```

Build edilmiş dosyalar `dist` klasöründe olacak.
